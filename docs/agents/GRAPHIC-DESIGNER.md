# FlopSource — Graphic Designer Agent Context

## Project Overview

FlopSource is a professional B2B directory for enterprise AI compute infrastructure (GPU clouds, bare-metal, and edge providers). It helps technical buyers evaluate and compare providers using data, weighted scoring, and AI recommendations.

The brand is deliberately **clean, trustworthy, and low-hype**. It is not trying to look like a trendy AI startup.

## Brand Positioning & Visual Direction

- **Professional & Serious**: Think high-quality internal tools or analyst platforms rather than consumer AI products.
- **Evidence-based and transparent**: Visual design should support clarity and trust, not decoration.
- **Modern but restrained**: Use contemporary design systems, but avoid excessive gradients, illustrations, or "AI magic" visual language.
- **Two surfaces**:
  - The actual directory tool (`website/flopsourcedirectory.html`) — more functional, data-heavy
  - The marketing landing page (root `index.html`) — cleaner, more polished marketing site with lead-gen focus (email grabber on AI + comparisons, subtle affiliate pathway)

## Target Audience Visual Expectations

- CTOs, infrastructure leads, procurement teams, and MLOps engineers
- They value clarity, data density, and professionalism over beautiful marketing visuals
- They are skeptical of hype and will notice when design feels overly "startup-y"

## Design Principles

- **Clarity first**: Information hierarchy is more important than visual flair.
- **Data-friendly**: Tables, filters, and comparison views need to be highly usable.
- **Consistent system**: Use a restrained color palette and typography system.
- **Light + Dark support**: The directory supports both corporate light and dark "bento" modes.
- **Avoid**:
  - Heavy use of gradients and glows (except subtle, purposeful ones)
  - Cartoonish or overly futuristic AI illustrations
  - Excessive whitespace that makes data feel sparse
  - Marketing-heavy visual language ("revolutionary", "next-gen", etc.)

## Current Visual Identity Notes

- Uses Tailwind CSS
- Primary accent is a sky blue (`#38bdf8` / `#2563eb` range)
- Clean sans-serif typography
- Functional card and table layouts
- Logo is a simple 2x2 grid mark (currently using white fills)

## When Creating or Suggesting Design Work

- Ask whether the work is for the **main directory tool** or the **marketing landing page** — they have different needs.
- For the directory: prioritize scannability, data density, and interaction clarity.
- For the landing page: you have more room for polish and marketing-friendly design, but still keep it professional.
- When designing icons or illustrations, keep them simple, geometric, and technical rather than playful.
- Prefer systems and components over one-off beautiful screens.

## Helpful Context

- The product competes on trust and usefulness, not on looking the most "AI-native".
- Many competing tools look flashy but lack real depth — FlopSource should feel like the serious, reliable option.
- Users are often evaluating expensive infrastructure decisions. The design should feel appropriately serious and helpful.
