# FlopSource Agent Description Files

This folder contains role-specific context documents designed to help different types of AI assistants work effectively on the FlopSource project.

## Available Descriptions

| Role | File | Purpose |
|------|------|---------|
| General AI Agent / Coding Assistant | [AGENT.md](./AGENT.md) | For coding agents, pair programmers, and general technical AI assistants (includes current lead-gen architecture and logging plans) |
| Graphic Designer | [GRAPHIC-DESIGNER.md](./GRAPHIC-DESIGNER.md) | For visual design, UI/UX, branding, and illustration work |
| Social Media Marketer & Manager | [SOCIAL-MEDIA-MARKETER-MANAGER.md](./SOCIAL-MEDIA-MARKETER-MANAGER.md) | For content strategy, social media, and marketing communications |
| Community Manager | [COMMUNITY-MANAGER.md](./COMMUNITY-MANAGER.md) | For community building, moderation, and engagement strategy |

## How to Use These Files

Copy the relevant file(s) into the context when working with an AI assistant on FlopSource-related tasks. This helps the AI understand:

- The project's positioning and target audience
- The desired tone and quality bar
- Role-specific priorities and constraints
- What "good" looks like for that type of work

These files are meant to be living documents. Update them as the project evolves or as you learn what context is most valuable for each role.
